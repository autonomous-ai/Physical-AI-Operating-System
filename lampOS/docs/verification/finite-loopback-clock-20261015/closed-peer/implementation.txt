Implementation
- Channel sets UnixStream nonblocking once. write_frame tries the current unsent suffix first and waits through rustix::event::poll(OUT) only on WouldBlock. Interrupted operations retain the same absolute end.
- A private BoundedReader tries read first, then poll(IN) on WouldBlock. read_frame stores the caller's absolute end for every partial read and checks it even before taking already-buffered frame bytes. It clears that override on success or error.
- HUP/ERR wake I/O so queued bytes, actual EOF, or the real socket error are read; HUP is never treated as immediate EOF. NVAL returns an error. No SO_RCVTIMEO/SO_SNDTIMEO calls remain in Channel and EINVAL is not ignored.
- Poll receives a positive remaining budget and caps each syscall chunk at i32::MAX milliseconds, retaining the original absolute end if a caller chooses a larger bound. EINTR and spurious readiness never reset the budget.
- Existing raw-reader test probes still use bounded Read semantics. Their test-only set_read_timeout stores a local budget and never modifies socket options; None/zero are rejected. Normal direct raw reads use the channel watchdog.
- Wire framing, LF/4096-byte cap, complete/truncated EOF distinction, all role/round/counter/terminal checks, fail-close ownership and existing deadline/error helper bodies are unchanged. No process termination, clock advancement, or logical-end/OS-exit substitution is added.
