# Final serve candidate on Lamp-4ace

The final composed Rust candidate handled eight original cached inputs in one
native provider session: six completed replies and two deliberately superseded
turns (3 during speech, 5 before output). Runtime and outer transport exited 0;
all relay-owned processes were reaped and stationary muted legacy restoration
verified. All eight prepared-player deliveries were valid. This is useful
supervised-pilot evidence, not a clean acceptance pass or a finished V2 release.

One completed answer contained a 30 ms accepted-zero supply gap. The separate
470 ms zero interval in turn 3 followed an intentional duplex yield with reply
audio still queued; it is retained as yield/cancellation, not supply starvation.
The coffee interruption elicited “Could you clarify what you're smelling?”
instead of an explanation. Its input transcript omitted the topic at the start;
that supports investigating lost opening words but does not prove where they
were lost. The correction to multiplication and later division were answered.

The room recorder is **invalid_capture**: one queue overflow dropped 13,824
48 kHz frames at source time 193.205–193.493 s, after the roughly 75-second
conversation. It remains invalid; no acoustic metric or human-listened claim is
made. The exact observer process exited. The evaluator's original failed report
is also retained: some cancellation findings disagree with the raw event order,
and its 600 ms profile label differs from the actual 1,200 ms policy. Neither
exit zero nor those reporting disagreements turn this into a clean benchmark.

The first stage attempt was refused before any service/audio action because its
saved ALSA hash no longer matched. Root reviewed the actual routing/card IDs,
pinned those exact bytes for a new cohort and removed one terminal newline from
each expected mixer string to match the existing stripped readback. No routing
or gain was changed, and the original refused attempt is preserved.

[Exact software counts, transcripts, artifact hashes and limitations](results.json)
are retained here. The source is code-identical to the final ARM snapshot at
`a9cae6d17`; documentation was published at `50dcc5794`. No new V1 comparison
was run. The new binaries are installed immutably, but the completed test restored
the old stationary muted services. Starting an attended pilot remains a separate
exclusive handover, followed by facilitator mute/reopen and chair-volume checks.
Camera and motors were disabled. Body choreography and robust multi-speaker
interaction are not qualified by this run.
